How to use these notes

  • Search any topic or formula from the box at the top, for example “refractive index” or “F = ma”.
  • Read the solved examples step by step, then cover the solution and try them yourself.
  • Revise with the summary at the end of each chapter the night before a test.
  • Print any chapter using the print button on its page; the layout is made for A4 paper.
